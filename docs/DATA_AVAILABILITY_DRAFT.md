# Data and code availability

## Code availability

The author-developed analysis and reproduction code is publicly available under the MIT License at https://github.com/FENG1567/global-surgical-coverage (version v1.0.1). The repository includes scripts and aggregate inputs for reproducing figures and tables, refitting municipality-level models, and checking the reported results, together with environment specifications and source-data provenance. The authors’ aggregate results and figures are licensed under CC BY 4.0. Reconstructing the full spatial analyses requires the third-party geographic and registry inputs listed in the repository’s external-data manifest, obtained under the providers’ terms.

## 代码可用性

本研究自编分析与复现代码以MIT许可公开于https://github.com/FENG1567/global-surgical-coverage（版本v1.0.1）。仓库提供图表复现、市级模型重新拟合及结果核验所需的脚本和汇总输入，并附环境要求与源数据记录。作者自有汇总结果与图稿采用CC BY 4.0许可。完整空间分析的重建需按原提供方条款，另行获取仓库外部数据清单所列的地理与登记输入。

## Data availability

Aggregate analytical results, figure source data, municipality-level analytical inputs and out-of-fold predictions are available in the same repository. Third-party raw data remain available from their providers under their original terms; see metadata/external_data_manifest.csv and THIRD_PARTY_NOTICES.md.
